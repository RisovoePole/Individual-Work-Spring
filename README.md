Topic of the work: Schedule generation using a genetic algorithm

## @Component

- Автоматическое обнаружение: Классы с @Component автоматически находятся Spring Boot, если они лежат в пакетах, сканируемых приложением (обычно это пакет, где находится класс с @SpringBootApplication). 
- Стереотип: Это общий стереотип. Специализированные аннотации, такие как @Service (логика), @Repository (хранилище данных) и @Controller (представление), наследуют @Component и предоставляют дополнительный функционал.
- Синглтон: По умолчанию создается один экземпляр бина (Singleton).

## Входные данные в систему

### Рассматриваем случай: составления расписания одного факультета на один учебный семестр

- **Список групп студентов**
  
  Каждая группа состоит из:
  - идентификатор группы
  - количество студентов
  - выбранная специальность

- **Список специальностей** (для рассматриваемого факультета)

  Каждая специальность состоит из:
  - названия
  - количество семестров обучения (можно и лет)

- **Список дисциплин** (для каждой специальности)

  Каждая дисциплина состоит из:
  - название
  - в каком семестре она изучается
  - необходимый тип аудитории
  - в какой специальности изучается
  - количество кредитов
  - количество контактных часов
  - количество независимых часов
  - количество часов на курсы
  - количество часов на семинары
  - количество часов на лабораторные

- **Список профессоров** (которые могут вести хотя бы одну дисциплину из рассматриваемой специальности)

  Каждый запись профессора состоит из:
  - Имя
  - Фамилия
  - Email
  - Список дисциплин, которые профессор может вести

- **Список доступных аудиторий**

  Каждая аудитория состоит из:
  - идентификатора
  - списка типов(тегов) данной аудитории

### Additional points

- Импорт почти всех настрое входных данных с помощью csv
- Экспорт конечной таблицы в XLSX
- Настройка кол-во рабочих дней, сколько длится пара, сколько длится перемена.

#### Формат экспорта результата генерации расписания

Общее расписание:

- несколько файлов: каждый файл для определённого года поступления группы.

  например, если прямо сейчас учатся 5 потоков, то будет 5 отдельных файлов: один на  поток.

- В одном файле будет отдельная таблицы на каждый рабочий день.

  таблица на один рабочий день состоит из:

  - по строкам время
  - по столбцам группа

  в ячейке написано кто, что и где ведёт. Если цикличны не одна неделя, то так же будет написано, в какие именно недели будет проведена пара. например у нас две недели - чётная и не чётная; написано чётная- значит только в чётную; если ничего не написано значит проводиться каждую неделю.
